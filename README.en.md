AI Resource Hub consolidates curated toolsets, official API consoles, an ecosystem map of AI Agents, academic research automation, model pricing calculators, and API connectivity reports into a unified web portal.

## Key Features

- **Categorized Tool Catalog**: 10+ categories spanning General AI Assistants, AI Search, Science & Research, Coding/Agent platforms, and Model Playgrounds.
- **Model Pricing & Comparison**: Searchable matrix of LLM input/output tokens, context windows, and cost efficiency.
- **API Connectivity Matrix**: Real-time status snapshots across 16 major providers.
- **Bilingual Experience**: Instant toggle between Simplified Chinese and English via avatar dropdown or mobile drawer (`[L]` shortcut).
- **Responsive & Dark Theme**: Built-in dark mode, touch-friendly 40px targets, and mobile slide-out drawer.

## Quick Start

Open `index.html` in any modern web browser or serve locally:

```powershell
python -m http.server 8080
```
